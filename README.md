# Nicholas Griffiths Portfolio

Personal portfolio app built with React, TypeScript, Tailwind CSS, and Vite.

## Tech Stack

- React 19
- TypeScript (strict mode)
- Tailwind CSS
- Vite
- React Router

## Scripts

- `npm run dev` - Start local development server
- `npm run build` - Type-check and create production build in `dist/`
- `npm run preview` - Preview production build locally
- `npm run typecheck` - Run TypeScript checks only
- `npm run lint` - Run ESLint

## Local Development

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open:

- `http://localhost:5173/` for the portfolio home page
- `http://localhost:5173/thank-you` for the thank-you page

## Notes

- Global default styling rules live in `src/styles/global.css`.
- App source uses TypeScript files (`.ts` and `.tsx`).
- Static assets are served from `public/assets/`.
